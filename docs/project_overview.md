# ASTRA HEALTH
## Project Overview

**Team:** VANGUARD POLARIS  
**Challenge:** Create Health Monitoring Software for Astronauts on Space Missions  
**Platform:** Python and Streamlit

### 1. Introduction

ASTRA HEALTH is an interactive health-monitoring software concept designed to support astronaut health awareness during space missions.

Space missions expose astronauts to challenging conditions, including microgravity, isolation, changes in sleep patterns, radiation exposure, and a restricted living environment. These conditions make continuous health monitoring and timely communication of health concerns important.

ASTRA HEALTH brings multiple health indicators together in one interface to help organize health information, identify noteworthy changes, and prepare structured reports for medical review.

### 2. Project Goal

The main goal of ASTRA HEALTH is to provide a clear and interactive system that helps astronauts and mission medical teams review health-related information throughout a space mission.

The software aims to:
- Collect and organize health-related measurements and self-reported symptoms.
- Display health information through an interactive dashboard.
- Allow users to select body regions and report symptoms.
- Review changes in available measurements over time.
- Highlight selected conditions that may require attention.
- Generate structured health reports for medical review.

### 3. Main Features

**Interactive Body Map**

Users can select different body regions and record symptoms associated with those areas.

**Health Monitoring Dashboard**

The dashboard presents available health indicators, such as heart rate, blood pressure, body temperature, sleep duration, and mood.

**Alert Assessment**

The system evaluates entered information using the currently implemented demonstration rules and displays relevant alerts.

**Health Trend Analysis**

Available records can be compared over time to help identify changes in health-related measurements.

**Medical Handover Reports**

Symptom reports can be organized into structured records to support communication with a crew medical officer or mission medical team.

**Data Export**

The application can export selected records in a structured format for further review.

### 4. Intended Users

The intended users include:
- Astronauts participating in space missions.
- Crew medical officers.
- Mission medical support teams.
- Researchers studying astronaut health monitoring.

### 5. Technology

The current prototype uses:
- Python for application logic.
- Streamlit for the interactive web interface.
- Pandas for data organization.
- NumPy for numerical operations.
- Plotly for interactive charts and visualizations.

### 6. Project Scope

ASTRA HEALTH is currently a research and demonstration prototype.

It is not a certified medical device, does not provide medical diagnoses, and does not replace professional medical judgment or official mission emergency procedures.

The current demonstration may use synthetic or manually entered data. It is not yet connected to real astronaut medical sensors or operational NASA systems.

### 7. Expected Impact

ASTRA HEALTH aims to make astronaut health information easier to review, organize, and communicate.

By combining interactive symptom reporting, health indicators, trend visualization, and structured handover reports, the project explores a practical approach to supporting health monitoring during future space missions.
